 

🛍️ Catálogo Web Sublimagic personalizado com Painel Admin 

Aplicação web desenvolvida para exibição de catálogo de produtos personalizados e gerenciamento dinâmico de estoque via painel administrativo.  

O projeto conta com integração em tempo real com o Supabase para persistência de dados de produtos e armazenamento de imagens (Storage).

🌐 Aplicação rodando (Live Demo): [https://rayssamartins23.github.io/catalogo-online-sublimagic/]

🛠️ Tecnologias Utilizadas 

Front-end:  

HTML5 (Estrutura semântica) 

CSS3 (Estilização e layout responsivo) 

JavaScript Vanilla (ES6+, manipulação do DOM e Fetch API) 

Backend as a Service (BaaS): 

Supabase (PostgreSQL para banco de dados) 

Supabase Storage (Buckets para upload e hospedagem de imagens) 

 

🚀 Funcionalidades 

📱 Catálogo de Produtos (index.html) 

Listagem dinâmica de produtos cadastrados no banco de dados. 

Exibição de imagem, nome e preço atualizados em tempo real. 

Botão para direcionamento do pedido direto para o WhatsApp. 

🔐 Painel Administrativo (admin.html) 

Autenticação e controle de acesso ao painel. 

Formulário de cadastro de novos produtos. 

Upload de imagens diretamente para o bucket do Supabase Storage com vinculação automática da URL pública no banco de dados. 

 

💡 Desafios Técnicos Superados 

Upload e Manipulação de Mídias: Resolução do fluxo assíncrono de envio de arquivos via JS para o Supabase Storage e associação da URL pública gerada ao registro do produto. 

Manipulação Dinâmica do DOM: Renderização eficiente das informações vindas da API sem a utilização de frameworks externos.
